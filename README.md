# Really | Gyubin Fan Site

A non-official content website for organizing Gyubin-related public information, media links, timeline entries, and fan-facing updates.

## Project Positioning

This repository is a lightweight static content website. For portfolio review, the relevant value is not the fan-topic itself, but the implementation pattern:

- static site structure
- content-oriented frontend layout
- JSON-based content loading
- Vercel deployment workflow
- basic SEO / Open Graph metadata
- simple analytics and visitor-count integration

## Technical Notes

- Static HTML / JavaScript / Tailwind CDN
- JSON files under `/data` for timeline and news content
- Static image assets under `/images`
- Designed for Vercel static hosting

## Portfolio Role

This is a secondary / optional portfolio item.

It can be used to demonstrate basic frontend publishing, static content maintenance, and deployment experience, but it should not be the main project for MIS, security, or infrastructure-focused job applications.

## Data and Content Boundary

- This is a non-official fan site.
- Public information and public media links should be used carefully.
- Do not include private personal information, private messages, private images, credentials, tokens, or copyrighted assets without permission.
- Any automated content update flow should keep source attribution and content licensing in mind.

## Resume-safe Summary

Built and maintained a static content website with JSON-driven sections, basic SEO metadata, and Vercel deployment workflow. This project demonstrates lightweight frontend publishing and content maintenance experience.
